# Monitoreo de Biodiversidad mediante ADN Ambiental (eDNA)
## Descripción
Este proyecto tiene como objetivo organizar y documentar un flujo de trabajo bioinformático para el análisis de ADN ambiental (eDNA).
El ADN ambiental permite detectar organismos presentes en un ecosistema a partir del material genético encontrado en muestras de agua, suelo o sedimento
## Objetivos
- Organizar muestras ambientales.
- Gestionar secuencias obtenidas mediante análisis molecular.
- Procesar datos utilizando herramientas bioinformáticas.
- Generar tablas y visualizaciones de resultados.
- Aplicar herramientas de control de versiones mediante Git y GitHub.
## Flujo de trabajo general
1. Recogida de muestras ambientales.
2. Extracción de ADN.
3. Secuenciación.
4. Control de calidad de las secuencias.
5. Identificación de especies.
6. Generación de resultados e informes.
## Estado del proyecto
Proyecto académico en desarrollo.
## Estructura del proyecto
- datos/: almacenamiento de muestras y datos procesados.
- secuencias/: secuencias obtenidas a partir de muestras ambientales.
- scripts/: scripts de procesamiento y análisis.
- resultados/: tablas e informes generados durante el análisis.
- figuras/: gráficos y visualizaciones.
- documentacion/: documentación técnica y metodológica.
